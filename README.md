# TaskFlow ⚡

> **Work smarter, ship faster.**
> A premium, distraction-free task management app built for the Synent Technologies Web Development Internship.

---

## 📌 Project Overview

**TaskFlow** is a startup-quality task management web application that goes beyond a basic to-do list. Designed with a dark premium aesthetic inspired by Linear, Vercel, and Framer, TaskFlow features glassmorphism cards, animated statistics, smooth micro-interactions, and full localStorage persistence — all without a single framework.

This project was developed as a flagship internship submission for the **Synent Technologies Web Development Internship Program**, demonstrating professional frontend skills including design systems, responsive layout architecture, accessible markup, and modular vanilla JavaScript.

---

## ✨ Features

| Feature | Description |
|---|---|
| ➕ Add Task | Type and press **Enter** or click **Add** |
| ✅ Complete Task | Click the checkbox — animated green tick |
| 🗑️ Delete Task | Hover any card to reveal the delete button |
| 🧹 Clear Completed | One-click to remove all done tasks |
| 💾 Persistence | Tasks saved via `localStorage` — survive page refresh |
| 📊 Live Statistics | Total / Completed / Pending counters with animated values |
| 📱 Responsive | Mobile-first layout — works on all screen sizes |
| 🎨 Premium UI | Glassmorphism, animated blobs, micro-interactions |
| ♿ Accessible | ARIA labels, keyboard navigation, focus management |
| 🌗 Dark Theme | Deep navy/near-black with violet × cyan gradient accents |

---

## 🛠️ Technologies Used

- **HTML5** — Semantic structure, ARIA roles, accessibility
- **CSS3** — Custom Properties (design tokens), Flexbox, Grid, Glassmorphism, `@keyframes`
- **Vanilla JavaScript (ES2020)** — Modular, well-commented, no frameworks
- **localStorage API** — Client-side persistence
- **Google Fonts** — Outfit (display) + Inter (body)

> Zero dependencies. Zero build tools. Zero frameworks.

## 🚀 Installation & Setup

### Option 1 — Open directly

```bash
# Clone or download the repository
git clone https://github.com/your-username/taskflow.git
cd taskflow

# Open in your browser
open index.html
```

No build step needed. Works offline.

### Option 2 — GitHub Pages (recommended for portfolio)

1. Push to a GitHub repository
2. Go to **Settings → Pages**
3. Set **Branch** to `main`, folder to `/ (root)`
4. Visit `https://your-username.github.io/taskflow`

### Option 3 — Netlify (one-click deploy)

1. Drag the `TaskFlow/` folder into [app.netlify.com/drop](https://app.netlify.com/drop)
2. Live in under 30 seconds — no account required
