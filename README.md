

> # To-Do List App

## Objective

Develop a task management web application that allows users to efficiently manage daily tasks as part of the Synent Technology Web Development & Design Internship.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage

## Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Persistent storage using localStorage
* Responsive and user-friendly interface
* Clean and modern design
